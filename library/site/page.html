Changing a game later

  1. Ask in the project. In a new chat in the Child I Fun project, say which game to change and how.
  2. Claude restores the library. Every file on this page is read back in one step.
  3. Only the right files change. Claude edits the pieces involved, rebuilds the game, and play-tests it.
  4. A new version gets its own page. Earlier versions keep working exactly as they were.
  5. This library is updated. It always holds the newest source and a link to every version.
