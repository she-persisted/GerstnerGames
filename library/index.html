Music

Every song is written as notes in a small file and played by kit/music.js (simple songs) or kit/groove.js (dance-style songs with verses and choruses). No recordings, nothing copyrighted.

Changing a game later

  1. Ask in the project. In a new chat in the Child I Fun project, say which game to change and how.
  2. Claude restores the library. Every file on this page is read back in one step.
  3. Only the right files change. Claude edits the pieces involved, rebuilds the game, and play-tests it.
  4. The game's home page gets the new version. The old version is saved as its own archive page first, so it keeps working exactly as it was, and the home page keeps its link, QR card and high scores.
  5. A QR card ships with it. In the game's own colors and icons, checked to scan before it's sent.
  6. This library is updated. It always holds the newest source and a link to every version.
